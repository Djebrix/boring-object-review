Entry for the [The Most Boring Object, Reviewed in One Line](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3) bounty on make.fun.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt` when set).
The program is Python 3 stdlib only, deterministic, and reads no input.
